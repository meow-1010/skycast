# SkyCast ☁️

SkyCast is a modern weather forecasting web application built using React and TypeScript.

## Features

- Real-time weather updates
- 7-day forecast
- Dark mode support
- Responsive modern UI
- Search locations worldwide
- Smooth glassmorphism design

## Tech Stack

- React
- TypeScript
- Vite
- CSS3
