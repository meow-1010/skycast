# SkyCast ☁️

SkyCast is a modern real-time weather forecasting web application built with React, TypeScript, and Vite.

It provides live weather updates, temperature forecasts, location search, dark mode support, and a clean glassmorphism-inspired UI.

---

## 🚀 Live Demo

https://your-vercel-link.vercel.app

---

## ✨ Features

- 🌍 Real-time weather updates
- 🔎 Search weather by city/location
- 📅 Multi-day weather forecast
- 🌙 Dark mode support
- 📱 Fully responsive design
- ⚡ Fast performance with Vite
- 🎨 Modern glassmorphism UI
- 🌡 Temperature and weather details
- 📍 Location-based weather search

---

## 🛠 Tech Stack

- React
- TypeScript
- Vite
- CSS3
- OpenWeather API (or your weather API)
